# Security Policy

## Supported Versions
Only the latest release and main branch are currently supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| main    | :white_check_mark: |

## Reporting a Vulnerability
If you discover a security vulnerability within AJProxy, please do not disclose it publicly via issue trackers.

Instead, report it directly via email:
- **Email:** jafarovabdul012@gmail.com

Please include a detailed description of the flaw, reproduction steps, and impact. Vulnerabilities will be evaluated and patched promptly.
